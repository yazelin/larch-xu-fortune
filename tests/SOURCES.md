# 測試採用的外部對照

干支日測試的預期值寫死在測試中，沒有用受測函式自行產生。全部採公曆日期的日干支，在當地午夜換日。

| 日期 | 日干支 | 對照出處 |
|---|---|---|
| 一九四九年十月一日 | 甲子 | GB/T 33661—2017《農曆的編算和頒行》六點三點二的循環參考日。[標準原文鏡像](https://www.horticulture.cn/d-13448.html)。 |
| 二〇〇〇年一月七日 | 甲子 | [日曆網當日曆表](https://www.rili.com.cn/wannianli/2000/0107.html) 的日柱。另與 [calendar411](https://www.calendar411.com/hk/nongli/2000-1-7) 搜尋摘要對照；後者全文本次逾時，不列為全文核對。 |
| 二〇二四年一月一日 | 甲子 | [中央氣象署二〇二四年天文日曆](https://www.cwa.gov.tw/Data/service/notice/download/Publish_20231127145652.pdf) 搜尋索引列一日甲子、二日乙丑；並與 [日本國立天文台曆象年表](https://eco2.mtk.nao.ac.jp/koyomi/cande/pdf/cande2024.pdf)「一月一日的干支」對照。 |
| 二〇二四年一月二日 | 乙丑 | 同上氣象署日曆的搜尋索引。 |
| 二〇二四年二月十日 | 甲辰 | [日曆網當日曆表](https://www.rili.com.cn/wannianli/2024/0210.html) 的日柱。 |

本次氣象署整份 PDF 超過讀取工具大小限制，僅核對索引可見的條目，未完成整份逐頁校閱；因此沒有假稱以其全文核對二月十日。程式以二〇〇〇年一月七日為甲子日計日差，測試另含早於基準日、跨月、閏日與無效日期。

星座採一套固定日期近似表，二十四個交界日均列在 `core.test.cjs`，年首尾、閏日、四月三十一日另測。參照 [〈星星知我心？〉](https://www.mnd.gov.tw/File/8108) 所列日期。這些測試驗證日期表規則，不驗證出生時刻的天文移宮。

鳥卦與塔羅測試同種子完全重現、不同種子產生不同序列，且涵蓋全部三十二箋與二十二張牌。塔羅每次三張不同，正逆位均會出現；固定種子測試不代表真實卜術有種子算法。
